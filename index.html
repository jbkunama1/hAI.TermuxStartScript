hAI.TermuxStartScript

Configurable TUI Service Manager for Termux

Service Management

Start, stop, and restart SSH and Cloudflared tunnels via termux-services (sv).

Token Handling

Paste Cloudflared tokens directly in the terminal — no dialog inputbox issues.

Apps Menu

Structured access to OSINT, Recon, and Pentest tools with short descriptions.

Template-Ready

Config block at the top — edit paths and commands for any Termux installation.

Boot Support

Works with Termux:Boot for auto-start on device boot.

Status Overview

Real-time status for SSH, Cloudflared, and token storage in one view.

Quick Start

git clone https://github.com/YOUR_USERNAME/hAI.TermuxStartScript.git
cd hAI.TermuxStartScript
cp service.sh ~/service.sh
chmod +x ~/service.sh
nano ~/service.sh   # Edit CONFIG section
~/service.sh
